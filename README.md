# okpublisher.gr

Το site παρουσίασης του okpublisher (GitHub Pages, okpublisher.gr). Ελληνικά + αγγλικά σε μία σελίδα (`#en`).
Τα δείγματα posts είναι για φανταστική επιχείρηση. Η φόρμα στέλνει στο Apps Script της φόρμας (`FORM_URL` στο index.html). Ο κώδικάς του ζει πλέον στο `okpublisher/publisher` (`form/`) και ανεβαίνει αυτόματα (workflow «Deploy φόρμας»)· ο σύνδεσμος `/exec` δεν αλλάζει.
